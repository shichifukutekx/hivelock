# Contributing

Issues, ideas and bug reports are welcome.

Outside contributions need an agreement before they can be accepted. Please do not open a pull request until the terms have been agreed: write to sales@shichifukutekx.ae first. A contribution that arrives without one cannot be merged, however good it is.

To report a vulnerability, email sales@shichifukutekx.ae. Please do not open a public issue.

Run the checks before you share a change:

```bash
npm run typecheck
npm test
```
